# In Obsidian

**Cards.** `cards.py` owns the frontmatter keys it generates (`part`, `manufacturer`, `product_type`, `topology`, `vin_min` … `confidence_*`, `contested`, `verified_params`, `is_buck`, `converts_voltage`, `lcsc`, …) and the body above `## Notes`. Everything else — `category`, `verified`, `tags`, `aliases`, anything you add, and all of `## Notes` — is yours and survives every regeneration.

**Corrections.** To correct what extraction or classification got wrong, add a `fix` list to the card, one `field = value` per entry: `name`, `superseded_by`, `doc_type`, `product_type`, `topology`, `manufacturer`, `parts` (comma-separated), `title`, `revision`. The next ingest pass (at most 30 minutes away) applies them. `name` renames the document everywhere — folder, files, every wikilink in the vault — then drops the entry and appends the old name to `renamed_from`; the version rule from filing applies, so a name that joins a family holding a newer version lands as `SUPERSEDED - <name>`, and a newer one marks the family's older versions. `superseded_by = <document>` marks a document superseded when the names do not show the lineage; either way the card records `superseded_by`. A request that cannot be applied is recorded in `fix_refused` and not retried until the entry changes. The other fields override the extracted value in the `.data.json`, and so in the card, database and views; `corrected` lists them, and an entry that cannot be applied is shown on the card and flagged `fix_rejected`. `python file_pdfs.py rename` applies pending renames at once.

**Views.** `views/*.base` are Obsidian Bases views (Obsidian 1.9+, core plugin): Library, Needs review (low / flagged / verified), Power, LoRa. They filter on card properties, so they work whether Obsidian opens the whole vault or `AutoNotes/` alone. Embed one in a summary page with `![[LoRa.base]]`; Dataview queries work too.

**Search.** The `.text.txt` files are plain text, `.txt` rather than `.md` so Obsidian does not index them: multi-megabyte datasheets stalled the mobile app. Obsidian's own search therefore does not see them; `grep -n` gives page numbers, `build_db.py` puts every page in the full-text database, and LLM tools can read them directly. The card links each one as an attachment. Extracted text is escaped so it cannot become vault structure (`[[2:1]]` bit ranges, `#define`).
